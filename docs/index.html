2. Simple 60-Second Setup

Plain-English steps written for parents — no technical experience needed.

On an Apple Mac

  1. Open your Downloads folder and double-click the downloaded .dmg file.
  2. Drag PreTest Studio onto your Applications folder.
  3. Open Applications and double-click PreTest Studio.
Verified by Apple: Every Mac build is signed and notarised with an official Apple Developer ID, so it opens smoothly with zero warnings.

On a Windows 10 or 11 PC

  1. Open your Downloads folder and double-click PreTest-Studio-Windows-Setup.exe.
  2. Follow the 15-second setup wizard — no Windows admin password needed.
  3. Launch PreTest Studio from your Start Menu or Desktop.
Windows SmartScreen (Beta notice): If Windows shows a blue “Windows protected your PC” box, click More info and then Run anyway.

On a Chromebook, Android or iPad

  1. Click Launch Web App Now above in Chrome (or Safari on iPad).
  2. Optional: On a Chromebook or Chrome laptop, click the small Install icon on the right side of the address bar to pin it to your shelf.
  3. On iPad, tap Share → Add to Home Screen. Works completely offline afterwards.

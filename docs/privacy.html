PreTest Studio Privacy Policy

Effective date: 21 November 2026 · Applies to PreTest Studio on Windows (Microsoft Store & direct installer), macOS, and Chromebook/Web

1. Zero Collection of Personal or Child Data

PreTest Studio is designed offline-first for families and pupils. We do not require user accounts, logins, or cloud synchronisation, and we do not collect, transmit, sell, or share any personal information, pupil names, assessment scores, or usage analytics.

2. Local On-Device Storage

All student profiles, parent passcodes (hashed locally with PBKDF2-HMAC-SHA256), practice attempts, focus-sprint logs, and tamper-evident audit chains are stored exclusively on your own device inside the local application data folder (or local browser storage in the Chromebook web app). Parents can export encrypted local backup files or delete local data at any time.

3. Optional External Features

  • Automatic App Updates (Direct Desktop Builds): Direct macOS and Windows installers check a static public release manifest (latest.json) hosted on GitHub Releases to notify parents of new versions. No personal identifiers or student data are sent. Microsoft Store installations are updated automatically by the Microsoft Store.
  • Optional Parent-Configured AI Tutor: The built-in Socratic Coach works 100% offline by default. If a parent explicitly enables an external OpenAI-compatible AI endpoint inside the passcode-protected Parent Command Centre, only the current practice question text and optional pupil thought prompt are sent directly from your device to the provider you configured. No student names or account profiles are included, and this feature is disabled by default and locked off during Timed Mocks.

4. No Third-Party Advertising or Trackers

PreTest Studio contains no advertisements, no third-party advertising SDKs, no behavioural tracking, and no telemetry beacons.

5. Contact

For privacy questions or support, please visit our public releases page at github.com/GitDakky/pretest-studio-releases.
